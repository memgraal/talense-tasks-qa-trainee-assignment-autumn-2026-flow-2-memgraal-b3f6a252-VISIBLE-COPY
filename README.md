# QA trainee assignment — Autumn 2026

Решены обязательная часть 1 по приложенным скриншотам и вариант 2.1 (API). Автотесты используют только стандартную библиотеку Python; сторонние зависимости не нужны.

## Запуск

Нужен Python 3.10 или новее. Из корня папки выполните:

```bash
python -m unittest -v test_api.py
```

По умолчанию тесты обращаются к `https://qa-internship.avito.com`. Для другого стенда задайте `QA_API_BASE_URL`, например:

```bash
QA_API_BASE_URL=https://example.test python -m unittest -v test_api.py
```

В PowerShell:

```powershell
$env:QA_API_BASE_URL = 'https://example.test'
python -m unittest -v test_api.py
```

При запуске создаются уникальные учётные записи и объявления. Тесты удаляют созданные объявления после проверки; у API нет ручки для удаления зарегистрированного пользователя, поэтому учётные записи тестового прогона остаются на стенде. Не используйте реальные пароли: секреты не нужны, тесты генерируют их самостоятельно.

## Состав

- `TESTCASES.md` — предусловия, шаги и ожидаемые результаты API-проверок.
- `test_api.py` — исполняемые API-тесты с проверками ответов и очисткой объявлений.
- `BUGS.md` — дефекты, найденные при сравнении исходных скриншотов.
- `PROMPTS.md` — использованные инструкции для работы с ИИ.
- `postman_collection.json` — коллекция из задания.
- `edit-form.png`, `seller-card.png`, `item-card.png` — исходные скриншоты для баг-репортов.
- `qa-trainee-assignment-autumn-2026.md` — исходное описание задания.

Неожиданный статус или нарушение ожидаемого результата выводится unittest вместе с ID проверки и endpoint. Проверки отправляются на общий стенд; они не предполагают фиксированный список объявлений или заранее известные ID.
